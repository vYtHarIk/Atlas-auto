# АТЛАС АВТО

Учебный проект по варианту 11 «Запись на тест-драйв и бронирование автомобилей
в автосалоне». Сейчас выполнено **занятие 7** из блока «7–9. Разработка
интерфейса пользователя»: каркас Django-проекта, шаблоны, статика, именованные
маршруты и главная страница по макету занятия 6.

## Стек

- Python 3.14, Django 6.1
- SQLite (на следующих занятиях подключаются модели)
- HTML, CSS, JavaScript без фреймворков
- Шрифты: Inter (заголовки) и Roboto (текст); если они не установлены
  в системе, используется системный запасной вариант

## Запуск

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Сайт откроется на <http://127.0.0.1:8000/>.

Секретный ключ и режим отладки читаются из переменных окружения
`DJANGO_SECRET_KEY` и `DJANGO_DEBUG`; локальные значения по умолчанию годятся
только для учебной машины.

## Структура

```
config/           настройки проекта и корневой urls.py
autosalon/        приложение автосалона: views.py, urls.py, demo_data.py
templates/        base.html и шаблоны страниц
static/css/       main.css — стили и переменные из UI-kit
static/js/        main.js — меню-бургер
static/img/       изображения автомобилей и favicon
```

### Маршруты

| Имя | Адрес | Назначение |
| --- | --- | --- |
| `autosalon:home` | `/` | Главная страница |
| `autosalon:catalog` | `/catalog/` | Каталог автомобилей |
| `autosalon:car_detail` | `/catalog/<slug>/` | Карточка автомобиля |
| `autosalon:test_drive` | `/test-drive/` | Запись на тест-драйв |
| `autosalon:trade_in` | `/trade-in/` | Оценка авто в трейд-ин |
| `autosalon:about` | `/about/` | О салоне |
| `autosalon:contacts` | `/contacts/` | Контакты |
| `autosalon:register` | `/register/` | Регистрация |
| `autosalon:privacy` | `/privacy/` | Политика конфиденциальности |

Все ссылки в шаблонах строятся через `{% url %}`, нигде не используются
строковые адреса.

## Что сделано в занятии 7

- создано виртуальное окружение, установлен Django, созданы проект `config`
  и приложение `autosalon`;
- настроены `STATIC_URL`, `STATICFILES_DIRS`, `STATIC_ROOT`, `MEDIA_URL`,
  `MEDIA_ROOT`, каталог `templates`, локаль `ru-ru` и часовой пояс
  `Europe/Moscow`;
- добавлен `.gitignore` (venv, `__pycache__`, `db.sqlite3`, `.env`, `media`);
- свёрстана главная страница: шапка с навигацией, первый экран, этапы записи,
  каталог из трёх карточек, форма записи, подвал;
- разметка семантическая: `header`, `nav`, `main`, `section`, `article`,
  `footer`, один `h1`, последовательные уровни заголовков, `alt` у всех
  изображений, `width`/`height` и `loading="lazy"` ниже первого экрана;
- стили вынесены в один файл, цвета и отступы заданы CSS-переменными из
  UI-kit, инлайновых `style` нет;
- на мобильной ширине работает меню-бургер, вёрстка проверена на 360, 768,
  1024 и 1440 px: горизонтальной прокрутки нет ни на одной из ширин;
- настроены именованные маршруты приложения с пространством имён `autosalon`.

## Проверки перед сдачей занятия 7

- `python manage.py check` — ошибок нет;
- все девять маршрутов отвечают 200, несуществующий slug автомобиля — 404;
- `document.documentElement.scrollWidth` совпадает с шириной окна на 360, 768,
  1024 и 1440 px;
- меню-бургер открывается и закрывается, `aria-expanded` меняется, ссылки
  в меню построены через `{% url %}`;

## Демонстрационные данные

Модели и подключение базы к страницам — задача занятия 8. Пока карточки
автомобилей, этапы и интервалы тест-драйва лежат в `autosalon/demo_data.py`;
шаблоны уже построены на циклах, поэтому при переходе на ORM разметка не
изменится. Форма записи тоже сверстана, но заработает после занятия 9, когда
появятся Django-формы и серверная валидация.
